Who runs this tool

Feres Shorts Uploader is a private tool built and used only by Feres Othman to publish Feres Othman's own short videos. Contact: YOUR_EMAIL.

What it accesses

With the account owner's permission, the tool connects to Feres Othman's own accounts on YouTube, Instagram, Facebook and TikTok in order to:

  • upload and schedule those accounts' own videos, with their titles, descriptions and tags;
  • read statistics for those videos (views, likes, comments, shares, watch time and similar metrics);
  • read the public comments left on those videos.

It does not access any other person's account, and it does not post on behalf of anyone else.

How data is stored

Access tokens and the statistics the tool reads are stored privately on the owner's own computer or private storage. They are used only to publish videos and to measure how they perform.

Sharing

No data is sold, shared with third parties, or used for advertising. Comments are read only so the owner can see and answer them.

Google user data

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. YouTube data is accessed through the YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time from the Google account permissions page (myaccount.google.com/permissions) or from the connected apps settings of each platform. Stored tokens and statistics are deleted on request to the contact above.
